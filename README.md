# Paddison Dental Group — Website

Static site. No build step: open `index.html` or serve the folder as-is.

## Pages
| File | Purpose |
|---|---|
| `index.html` | Homepage |
| `before-after.html` | Patient results gallery |
| `book.html` | Consultation request form |
| `patient-forms.html` | Downloadable new-patient forms |

## Assets
`assets/` — hero video & poster, team and office photos, reviewer avatars,
`assets/ba/` before & after case photos, `assets/forms/` patient form PDFs.

## Deploy
Any static host. For GitHub Pages: Settings → Pages → deploy from branch, root folder.
`.nojekyll` is included so asset folders are served untouched.
